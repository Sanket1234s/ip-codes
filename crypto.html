1. Additive Cipher

Question

Write a program to implement the Additive cipher.
Plain text: “this message is easy to encrypt but hard to find the key”. Key: 15 (ignore the spaces between words).

Logic

Encryption: C = (P + k) mod 26. Decryption: P = (C − k) mod 26. Letters are numbered A=0 … Z=25.

4. Affine Cipher

Question

Write a program to implement the Affine cipher.
Plain text: “hello”. Key: (7, 2) (ignore the spaces between words).

Logic

Encryption: C = (a·P + b) mod 26. Decryption: P = a−1·(C − b) mod 26. Here a = 7 must have gcd(a, 26) = 1; its inverse is 15 because 7 × 15 = 105 = 1 mod 26.

Output

Key (a, b)   : (7, 2)
Inverse of a : 15

5. Autokey Cipher

Question

Plain text: “the house is being sold tonight”. Key: 7 (ignore the spaces between words).

Logic

The key stream is the secret key followed by the plain text itself: 7, T, H, E, … Encryption: Ci = (Pi + Ki) mod 26. While decrypting, each recovered letter becomes the next key.

6. Playfair Cipher

Question

Write a program to implement the Playfair cipher.
Plain text: “the key is hidden under the door pad”. Secret key: guidance.

Logic

A 5 × 5 matrix is built from the key (I and J share a cell). Plain text is split into pairs; a double letter gets an X between them and an odd last letter gets an X. Same row: take the letter on the right. Same column: take the letter below. Otherwise: swap the rectangle corners.

8. Hill Cipher

Question

Write a program to implement the Hill cipher.
Plain text: “we live in an insecure world”. Key matrix: first row (03 02), second row (05 07).

Logic

Letters are taken in pairs and multiplied by the key matrix: C = K·P mod 26. The determinant is 3×7 − 2×5 = 11, which has an inverse (19) mod 26, so the key is valid. Decryption uses the inverse matrix K−1. An odd length is padded with X.

9. Character Count Framing

Question

Write a program to implement the Character Count framing technique.
Input: A = 01000111, B = 11100011, FLAG = 01111110, ESC = 11100000. Frame: A B ESC FLAG.

Logic

The first field of the frame holds the number of characters in the frame, including the count field itself. The receiver reads the count and then takes exactly that many characters. Weakness: if the count is corrupted, the receiver loses synchronisation.

10. Byte (Character) Stuffing

Question

Write a program to implement the Byte Stuffing (Character Stuffing) framing technique.
Input: A = 01000111, B = 11100011, FLAG = 01111110, ESC = 11100000. Frame: A B ESC FLAG.

Logic

Each frame starts and ends with a FLAG byte. If a FLAG or ESC byte appears inside the data, the sender inserts an ESC byte in front of it. The receiver removes the flags and drops every ESC that was stuffed.

11. Bit Stuffing

Question

Write a program to implement the Bit Stuffing framing technique.
Input: A = 01000111, B = 11100011, FLAG = 01111110, ESC = 11100000. Frame: A B ESC FLAG.

Logic

The flag 01111110 has six 1s in a row. To keep it unique, the sender inserts a 0 after every five consecutive 1s in the data. The receiver removes a 0 that follows five consecutive 1s.
