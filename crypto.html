4. Affine Cipher

Question

Write a program to implement the Affine cipher.
Plain text: “hello”. Key: (7, 2) (ignore the spaces between words).

Logic

Encryption: C = (a·P + b) mod 26. Decryption: P = a−1·(C − b) mod 26. Here a = 7 must have gcd(a, 26) = 1; its inverse is 15 because 7 × 15 = 105 = 1 mod 26.

Answer (complete code)
Output (step-wise execution)
STEP 1: Remove the spaces and use capital letters
HELLO

STEP 2: Check that a and 26 have no common factor
gcd(7, 26) = 1  -> key is valid

STEP 3: Find the inverse of a (a x inverse mod 26 = 1)
7 x 15 = 105,  105 mod 26 = 1  -> inverse = 15

STEP 4: Encrypt using C = (7 x P + 2) mod 26

6. Playfair Cipher

8. Hill Cipher

Question

Write a program to implement the Hill cipher.
Plain text: “we live in an insecure world”. Key matrix: first row (03 02), second row (05 07).

Logic

Letters are taken in pairs and multiplied by the key matrix: C = K·P mod 26. The determinant is 3×7 − 2×5 = 11, which has an inverse (19) mod 26, so the key is valid. Decryption uses the inverse matrix K−1. An odd length is padded with X.

Answer (complete code)
Output (step-wise execution)

9. Character Count Framing

Question

Write a program to implement the Character Count framing technique.
Input: A = 01000111, B = 11100011, FLAG = 01111110, ESC = 11100000. Frame: A B ESC FLAG.

Logic

The first field of the frame holds the number of characters in the frame, including the count field itself. The receiver reads the count and then takes exactly that many characters. Weakness: if the count is corrupted, the receiver loses synchronisation.

Answer (complete code)
Output (step-wise execution)
STEP 1: Characters of the frame
  A    = 01000111
  B    = 11100011
  ESC  = 11100000
  FLAG = 01111110

STEP 2: Calculate the count (data characters + 1 for the count field itself)
  4 + 1 = 5   -> binary 00000101

STEP 3: Sender builds the frame = count field + data characters
  Count field : 00000101
  A           : 01000111
  B           : 11100011
  ESC         : 11100000
  FLAG        : 01111110
  Frame sent  : 00000101 01000111 11100011 11100000 01111110

STEP 4: Receiver reads the first byte to get the frame length
  First byte 00000101 = 5  -> frame has 5 characters (count included)

STEP 5: Receiver takes the next 4 characters as data
  character 1: 01000111  (A)
  character 2: 11100011  (B)
  character 3: 11100000  (ESC)
  character 4: 01111110  (FLAG)

STEP 6: Data received
01000111 11100011 11100000 01111110

10. Byte (Character) Stuffing

Question

Write a program to implement the Byte Stuffing (Character Stuffing) framing technique.
Input: A = 01000111, B = 11100011, FLAG = 01111110, ESC = 11100000. Frame: A B ESC FLAG.

Logic

Each frame starts and ends with a FLAG byte. If a FLAG or ESC byte appears inside the data, the sender inserts an ESC byte in front of it. The receiver removes the flags and drops every ESC that was stuffed.

Answer (complete code)
Output (step-wise execution)
STEP 1: Data characters
  A    = 01000111
  B    = 11100011
  ESC  = 11100000
  FLAG = 01111110

STEP 2: Sender checks every byte (FLAG or ESC in the data gets an ESC in front)
Byte   Is it FLAG or ESC?   Action
 A      no                   copy as it is
 B      no                   copy as it is
 ESC    yes                  put ESC before it, then ESC
 FLAG   yes                  put ESC before it, then FLAG

STEP 3: Data after stuffing
A B ESC ESC ESC FLAG
01000111 11100011 11100000 11100000 11100000 01111110

STEP 4: Add the FLAG at the start and at the end
FLAG A B ESC ESC ESC FLAG FLAG
Frame sent: 01111110 01000111 11100011 11100000 11100000 11100000 01111110 01111110

STEP 5: Receiver removes the flags and the stuffed ESC bytes
  A    normal -> keep it
  B    normal -> keep it
  ESC  found -> skip it, keep the next byte ESC
  ESC  found -> skip it, keep the next byte FLAG

STEP 6: Data received after destuffing
A B ESC FLAG
01000111 11100011 11100000 01111110
