9. Servlet Login (GET, POST, Cookie, Session, Logout)

Question

Design and develop a web application using Java Servlets and deploy it on Apache Tomcat. Create a login form for username and password. Implement a Servlet to process the login using HTTP POST and display an appropriate response. Demonstrate HTTP GET and POST handling. Use Cookies to store and retrieve user information and HTTP Session to maintain login state across requests. Include a logout option to end the session.

Answer (complete code)
Output

Admin / 1234 shows “Login Successful. Welcome admin” (cookie and session created). Wrong login shows a red error. View Profile (GET) shows the session user and cookie. Logout ends the session.

How to run (tools)
  1. Install Apache Tomcat 10 and Eclipse IDE for Enterprise Java. (With Tomcat 9, change jakarta to javax in both servlets.)
  2. In Eclipse: File → New → Dynamic Web Project, name it loginapp, choose Tomcat as the target runtime, then Finish.
  3. Put login.html in src/main/webapp. Right-click src/main/java → New → Class and create LoginServlet and LogoutServlet, pasting the code.
  4. Right-click the project → Run As → Run on Server → select Tomcat → Finish.
  5. Open http://localhost:8080/loginapp/login.html. Log in with admin / 1234, click View Profile, then Logout.

10. JSP + JDBC + MySQL (student records)

Question

Design and develop a web application using JSP to manage student information. Create a form for roll number, name, branch, semester and email. Connect to a MySQL database using JDBC and insert student records. Retrieve the stored records and display them dynamically on a JSP page in a table. Use HTML, JSP, JDBC and MySQL, and deploy on Apache Tomcat.

Answer (complete code)
Output

Submitting the form inserts a row, shows “Record inserted successfully.” and a table of all students.

How to run (tools)
  1. Start XAMPP (MySQL). Open phpMyAdmin, click the SQL tab and run the SQL code above to create the college database and student table.
  2. In Eclipse create a Dynamic Web Project named studentapp with Tomcat as runtime.
  3. Download the mysql-connector-j jar and copy it into src/main/webapp/WEB-INF/lib.
  4. Put student.html and display.jsp in src/main/webapp. In display.jsp change the MySQL password ("root") to your own (empty in XAMPP).
  5. Right-click the project → Run As → Run on Server. Open http://localhost:8080/studentapp/student.html, fill the form and submit.
