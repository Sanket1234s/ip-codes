Internet Programming - Practical Code Bank

13 experiments. Tap Copy on any file, or click inside a box and use Ctrl+A, Ctrl+C. “Run” previews the browser-only ones.

1. Resume (semantic HTML5)

header, nav, main, section, article, footer, list, image, table.

Output: name and photo on top, nav links, education table, skills list, two project articles, contact footer.

2. Weekly Timetable

table, tr, th, td with days, timings, subjects, rooms.

Output: bordered table, Monday to Friday, each cell shows subject and room.

3. Feedback Form with Audio and Video

required, type="email", placeholder, select, audio, video.

Output: form with validation messages, then audio and video players (add clip.mp3 and clip.mp4 next to the file).

Audio

Video

4. CSS3 Event Page (inline + internal + external)

Background colours, borders, text formatting, shadow, transform and transition. Colours in rgb().

Output: dark blue banner, yellow dashed info box, three cards that rotate and grow on hover.

5. Bootstrap Responsive Page

Grid system, colours, media query, hover animation. Needs internet for the Bootstrap CDN, so it is not previewed here.

Output: blue navbar, three coloured cards in a row on desktop and stacked on mobile, cards lift on hover.

6. Student Result Calculator

Form, JavaScript object, total, percentage, Pass/Fail.

Output: marks 78, 82, 69 give Total 229/300, 76.33%, Pass. Any subject below 40 gives Fail.

7. Event Registration Form

Validation, dynamic fields, try-catch with exceptions, success message.

Output: red message for the first invalid entry. Hackathon shows Team Size, Paper Presentation shows Paper Title, Quiz shows College Name. Valid input shows a green thank-you message.

8. Appointment Booking Form

Validation, time slots change with type, custom exception, try-catch, confirmation.

Output: choosing a type fills the time-slot list. Errors show in red (for example “Date cannot be in the past”). Success shows “Confirmed! Rahul, your Doctor appointment is on 2026-11-10 at 11:00 AM.”

9. Servlet Login (GET, POST, Cookie, Session, Logout)

Deploy in Tomcat: webapps/loginapp/login.html and the compiled classes in WEB-INF/classes. Tomcat 10+ uses jakarta; for Tomcat 9 change jakarta to javax. Open http://localhost:8080/loginapp/login.html

Output: admin / 1234 shows “Login Successful. Welcome admin” (cookie and session created). Wrong login shows a red error. View Profile (GET) shows the session user and cookie. Logout ends the session.

10. JSP + JDBC + MySQL (student records)

Run the SQL, add the mysql-connector-j jar to WEB-INF/lib, put both pages in a Tomcat webapp. Change the MySQL password in display.jsp.

Output: submitting the form inserts a row, shows “Record inserted successfully.” and a table of all students.

11. AJAX Student Dashboard

Keep all three files in one folder and open dashboard.html through a local server (for example VS Code Live Server). AJAX cannot read files opened with file://.

Output: two boxes. Update Details fills the left box, Update Results fills the right box, each without reloading the page.

12. XML + DTD + PHP (parse and display)

Put the three files in XAMPP htdocs/e12 and open http://localhost/e12/parse.php

Output: “XML is valid (DTD)” and a table of students (roll, name, branch, semester).
